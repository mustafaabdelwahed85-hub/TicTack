# 🎮 Neon Tic-Tac-Toe

A modern and interactive Tic-Tac-Toe web application built using **HTML, CSS, and JavaScript** with multiple AI difficulty levels, neon UI effects, responsive design, and smooth gameplay experience.

---

## 🚀 Live Demo

🔗 https://mustafaabdelwahed85-hub.github.io/TicTack/

---

## ✨ Features

- 🎯 Player vs Player Mode
- 🤖 Player vs AI Mode
- 🧠 3 AI Difficulty Levels
  - Easy
  - Medium
  - Hard (Minimax Algorithm)
- 🌌 Animated Neon Background
- 🏆 Win Detection & Animations
- 📊 Persistent Scoreboard using LocalStorage
- 🌗 Light / Dark Theme Toggle
- 💬 AI Interactive Messages
- 📱 Fully Responsive Design
- ♿ Improved Accessibility Support
- 🎨 Glassmorphism UI Design

---

## 🧠 AI Logic

The project includes different AI behaviors:

### Easy
- Random moves

### Medium
- Blocks player winning moves
- Attempts winning opportunities

### Hard
- Uses the Minimax algorithm
- Nearly unbeatable AI opponent
